# Triage labels

Issues carry one triage label. Apply with `gh issue edit <n> --add-label "<label>"`.

- `ready-for-agent`: fully specified, grabbable by an agent with no further triage. `/to-spec` and `/to-tickets` apply it to everything they publish.

Wayfinder labels (`wayfinder:map`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, `wayfinder:task`) are described in `issue-tracker.md`.
